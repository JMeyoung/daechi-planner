# 대치 플래너 — 학부모 유저 리서치

> 온라인 커뮤니티/뉴스/앱스토어 조사로 뽑은 학부모 실제 언어와 경쟁 지형 정리.
> 디스쿨 글쓰기는 지역 인증 필요 → 82cook 등 개방형 커뮤니티 우선 검토.

---

## 1. 학부모가 실제로 쓰는 언어 (글에 그대로 녹일 재료)

### 테마 ① 라이딩 지옥 / 학원 뺑뺑이
- "라이딩", "픽업", "하원" 이 일상 단어. 라이딩이라는 말이 따로 있을 만큼 자녀 송영이 삶의 중심.
- 다자녀일 때 **학원 시간이 겹쳐서 한 명 데려다주다 다른 애를 못 챙기는** 상황이 실제 고충으로 등장.
- → 글 후크 예: *"첫째 데려다주다 둘째 학원 시간 놓친 적 있으신가요?"*

### 테마 ② "한 달에 얼마 쓰는지도 모르겠다"
- 사교육비 월 평균: **고등 79만 / 중등 63만 / 초등 51만** (참여 학생 평균 60만 돌파, 역대 최고).
- 헤럴드경제: *"월 100만원씩 썼는데 알고보니 평균이었다"* → **부모가 자기 지출 규모를 모름.**
- → 글 후크 예: *"우리 집 학원비, 지금 한 달에 정확히 얼마인지 바로 답하실 수 있나요?"*

### 테마 ③ 정보력 = 엄마 실력 (정보 비대칭)
- *"국영수 1등 엄마만 안다"*, 좋은 정보는 **엄마들 사이에서 조용히 전달**.
- 입시 깜깜이 → 정보 가진 엄마와 못 가진 엄마의 격차가 곧 자녀 결과 격차라는 불안.
- → 글 후크 예: *"정보 빠른 엄마들만 아는 것들, 혼자 뒤처지는 느낌 드신 적 없으세요?"*

## 2. 경쟁 지형 — 점 단위로는 이미 존재, 통합·대치 특화는 빈자리

| 분류 | 서비스 | 입장/타겟 | 대치 플래너와 겹침 |
|------|--------|----------|----------------|
| 일정/픽업 | **하원나우** | 학부모용, **초등 저학년 픽업** (태권도·영어·미술, 동네 육아지원금) | 일정·비용 기능 겹침. 단 초등·전국 일반 |
| 학원비 관리 | **학원 고고** | 학부모용, 과목별/자녀별 지출·카드·알림 | 비용 기능 정면 겹침. 단 비용 전용 |
| 학원 정보/리뷰 | **강남엄마**(월 6만, 학원 10만·리뷰 5만), **디스쿨**, 학원의신 | 학원 찾기 O2O | 콘텐츠 일부 겹침 |
| 입시 컨설팅 | 이대로(AI 진단), 대교 마카다미아 | 입시 진단 | 콘텐츠 일부 |
| 학교 알림 | 아이엠스쿨(**2026.2.28 종료**), e알리미 | 학교→학부모 단방향 | 거의 안 겹침 |
| DIY | 노션 "우리 아이들 학원 스케줄 정리"(윤정리) | 학부모 직접 제작 | **수요 증거** |

### 핵심 통찰
- **개별 기능(일정·비용)은 이미 상품화됨** → "또 하나의 전국 일반 플래너"로는 차별화 0.
- 아무도 안 하는 것 = **대치동 중고등 입시 학부모 특화 + 큐레이션 콘텐츠(입시 브리프) + 일정·비용 통합.**
- **콘텐츠가 유일한 해자.** 일정·비용은 누구나 만들지만, "내 아이 플랜에 붙은 대치동 입시 정보"는 못 따라옴.
- 노션 템플릿이 마켓에 있다 = 학부모가 전용 앱이 없어 **직접 만들어 쓰는 중** = 수요 검증.

| 커뮤니티 | 접근성 | 타겟 적합 | 메모 |
